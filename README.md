# 🐕 24BP Dog Handbook System

Hệ thống sổ tay số hỗ trợ huấn luyện chó nghiệp vụ quân đội - Capstone Project SEP490-G52

## 📋 Giới thiệu

**Dog Handbook System (DHS)** là ứng dụng di động hỗ trợ offline, cung cấp cơ sở kiến thức số toàn diện về giống chó, giai đoạn phát triển, tiêu chuẩn dinh dưỡng và bài tập huấn luyện theo quy định của Bộ Quốc phòng.

Ứng dụng giúp người huấn luyện chó nghiệp vụ có thể tra cứu thông tin mọi lúc, mọi nơi mà không cần kết nối internet - đặc biệt hữu ích khi thực hiện nhiệm vụ tại thao trường, khu vực chiến thuật hoặc triển khai từ xa.

## 🛠️ Tech Stack

| Module    | Công nghệ                  |
|-----------|----------------------------|
| Backend   | Java, Spring Boot, MySQL   |
| Mobile    | React Native, Expo, SQLite |
| Web Admin | Next.js, TypeScript        |

## ✨ Tính năng chính

- 🔍 Tra cứu thông tin giống chó nghiệp vụ
- 📊 Theo dõi giai đoạn phát triển theo độ tuổi
- 🍖 Tra cứu khẩu phần dinh dưỡng và tính toán định lượng thức ăn
- 🎯 Xem bài tập huấn luyện với hướng dẫn từng bước và video minh họa
- 🏥 Tra cứu triệu chứng sức khỏe và hướng dẫn sơ cứu
- 💊 Danh sách thuốc thiết yếu với hướng dẫn sử dụng
- 📱 Hoạt động offline 100% trên thiết bị di động
- 📝 Hệ thống CMS quản trị nội dung
